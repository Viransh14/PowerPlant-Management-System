Relational Reports & SQL Analytics

Interactive views for Assessment queries (JOIN, GROUP BY, SUM, COUNT, ORDER BY)

Plant-wise Generation Report

JOIN + GROUP BY + SUM + COUNT
SELECT p.PLANT_NAME, p.CAPACITY_MW, NVL(SUM(g.UNITS_GENERATED),0) TOTAL_UNITS, COUNT(g.RECORD_ID) RECORD_COUNT FROM POWER_PLANT p LEFT JOIN GENERATION_RECORD g ON p.PLANT_ID=g.PLANT_ID GROUP BY p.PLANT_NAME, p.CAPACITY_MW ORDER BY TOTAL_UNITS DESC

Database Definition & Schema Manager

Execute DDL commands directly on Oracle Schema (CREATE, ALTER, INSPECT)

CREATE TABLE Demo

Creates MAINTENANCE_LOG with Foreign Key to POWER_PLANT.

CREATE TABLE MAINTENANCE_LOG (LOG_ID NUMBER PRIMARY KEY, PLANT_ID NUMBER REFERENCES POWER_PLANT(PLANT_ID), MAINTENANCE_DATE DATE, DESCRIPTION VARCHAR2(300), COST NUMBER)
ALTER TABLE Demo

Modifies MAINTENANCE_LOG schema to add column NOTES.

ALTER TABLE MAINTENANCE_LOG ADD (NOTES VARCHAR2(200))
